# Unitree D1 机械臂自主视觉抓取与投放

简体中文 | [English](README.md)

本项目基于 **Unitree D1-550 机械臂、Intel RealSense D435i 腕部相机和 ROS 2 Humble**，实现从视觉识别到抓取、携带和投放的自主作业流程。调用方只需提供物体的大致位置或投放点，机械臂模块负责感知、运动规划、动作执行及失败恢复，无需调用方指定抓取位姿或关节轨迹。

项目可在个人开发机上独立运行，也可部署到 Unitree Go2 的开发板上，为上层任务提供机械臂抓放能力。机器狗行走、导航及整体任务编排不属于本项目的范围。

## 功能与实现

- **视觉感知**：通过腕部 RealSense 获取 RGB-D 图像和 IMU 数据，结合 YOLO 识别、地面估计及物体几何信息计算抓取位姿。
- **自主抓取**：完成粗观测、精观测、预抓取、视觉微调、下降、闭合夹爪、抬升和携带，并在携带姿态下检查物体是否仍被夹持。
- **运动规划与控制**：使用 MoveIt 2 进行逆运动学求解和碰撞检查，通过项目内维护的 `unitree-d1-control` 板端控制服务执行真机动作。
- **自主投放与失败处理**：搜索释放位姿并检查往返路径，完成释放及收纳；通过状态机处理可恢复的任务失败，并向调用方返回下一步决策信息。
- **仿真与部署**：提供 MuJoCo 仿真验证、RViz 可视化，以及面向 amd64 开发机和 arm64 Go2 开发板的 Docker 部署脚本。

当前支持黄色立方体、西葫芦类条状物和碗三类目标，**不是任意物体的通用抓取方案**。物体规格与图片见[物体说明](docs/api/objects/README_CN.md)。更换物体、机械臂或相机安装方式后，需要按实际情况调整感知模型及标定参数。

## 部署教程

[中文版部署教程](deploy/README_CN.md)介绍硬件连接、Docker 环境构建、D1 板端控制服务更新、参数配置，以及仿真和真机功能验证。

教程包含两种部署方式：

- **个人开发机（amd64）**：用于独立开发、调试和验收机械臂服务。
- **Unitree Go2 开发板（arm64）**：用于将机械臂服务集成到机器狗系统；建议先完成开发机上的验证。

腕部相机支架的打印文件与安装说明见[相机支架文档](hardware/wrist_camera_mount/README_CN.md)。

## API 文档

[中文版 API 文档](docs/api/README_CN.md)面向调用方，说明接口调用方法、请求参数、过程反馈、最终结果及状态流转，并提供命令行、Python 和 C++ 示例。

| 接口 | 形式 | 用途 |
| --- | --- | --- |
| `/arm/tasks/pick_object` | ROS 2 Action | 根据物体大致位置执行自主抓取并进入携带姿态 |
| `/arm/tasks/drop_object` | ROS 2 Action | 根据投放目标执行释放并返回收纳姿态 |
| `/arm/task_status` | ROS 2 Topic | 获取机械臂当前任务状态、载荷状态和故障信息 |

调用方根据 Action Result 中的 `outcome` 决定继续任务、调整位置、重新指定投放点或进行人工排障；状态 Topic 用于监控机械臂状态。
